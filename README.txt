VPS＋人工ランドマーク案内（スマステ）HTML版

画像による位置推定（VPS）に、人工ランドマーク（AprilTag 36h11）による位置推定を加えた版です。
写真に登録済みの目印が写っていれば目印で、写っていなければVPSで現在地を推定します。

【中身】
index.html　案内アプリ
opencv.js　画像処理エンジン
dict.json　VPSの辞書（128枚分の特徴点）
station.json　構内図の座標・撮影地点・通路・目印の登録
plans/　簡略構内図（1F・3F）
markers/　目印の印刷用PDF（A4、ID0〜7、黒い四角の一辺160mm）

【GitHub Pagesでの公開手順】
1. GitHubで新しいリポジトリを作る
2. このフォルダの中身をすべてアップロードする
3. Settings → Pages → Branch を main ／ (root) にして Save
4. 数分後に表示されるアドレスを、iPhoneのSafariで開く

【目印の登録】
案内の設定 → 目印 → IDと「面が向く方向」を選び、地図上の貼った場所をタップ。
この端末にだけ保存されます。全端末に反映するには、書き出し → 設定（station.json）で書き出し、
このリポジトリの station.json と差し替えてください。

【注意】
・構内図・辞書・座標が誰でも見られる状態で公開されます。
・ログはその端末のブラウザ内に保存されます。実験後は 案内の設定 → ログ で必ず書き出してください。
